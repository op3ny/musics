# 🎵 Musics

Minha biblioteca pessoal de músicas, organizada e disponibilizada em arquivos `.zip` para facilitar o download e a preservação.

A biblioteca é utilizada pelo **Swing Music** e pode ser acessada através da minha instância:

🌐 **https://thais.sytes.net** (*Não está aberto ao público...)

## 📦 Conteúdo

Este repositório contém cópias compactadas da minha biblioteca musical.

```text
musics/
├── README.md
└── *.zip
```

Os arquivos `.zip` contêm as músicas da biblioteca, mantendo a organização utilizada no meu servidor de música.

## 🎧 Swing Music

A biblioteca é gerenciada e reproduzida através do **Swing Music**, um servidor de música pessoal com interface web.

> Este repositório funciona como uma forma alternativa de distribuir/armazenar a biblioteca em arquivos compactados.
